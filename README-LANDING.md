# PentSim Landing Page

A responsive, single-file marketing landing page for the PentSim virtual penetration testing academy.

## Preview locally

From this directory, run:

```bash
python3 -m http.server 8080
```

Open http://localhost:8080/landing.html

The landing page links to `index.html`, the existing interactive PentSim frontend prototype.

## Notes
- Pure HTML, CSS and JavaScript; no build step or external dependencies.
- Responsive navigation, FAQ accordions, CTA links, and dashboard-style visual mockup.
- Metrics in the hero and competency preview are illustrative demo data.
- The page accurately distinguishes the simulated frontend prototype from future real isolated lab execution.
